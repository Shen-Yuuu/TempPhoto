「临时相机」UI 重构 · 风格方案预览

三个候选方向，每个方向展示三个核心页面（首页 / 相机页 / 详情页）的高保真布局稿。以下所有方案共享同一批"通用升级点"，选定方向后将原样落地为 ArkUI 实现，不改业务逻辑。

通用升级点（无论选哪个方向都会做）

  • 设计 token 化：统一色板、圆角体系（8/12/16/24）、4pt 间距网格、字阶（10/12/14/16/22/28）
  • 倒计时全部改用等宽数字（tabular mono），精确到分钟，读数不再抖动
  • 寿命余量可视化：每张照片都能一眼看出"还剩多少生命"（余量条 / 进度环）
  • 空态与权限引导页重设计：插画 + 单一行动点，替代纯文字
  • 状态栏沉浸处理；相机页全屏取景；触控目标 ≥ 44vp
  • 信息架构调整：宫格长按快捷菜单（分享 / 存相册 / 删除）
方案 A

暗房 Darkroom

全暗色 · 相机语言

整套应用沿用专业相机的暗房语言：暖调炭黑底、快门橙作唯一强调色。签名元素是每张照片底部的"寿命引线"——一条随剩余时间缩短的琥珀色细条，照片像定时装置一样在眼前"燃尽"。倒计时与统计数字全部使用等宽数字，强化计时器的机械感。适合强调"这是一台相机，不是一个相册"。

#141210 底 #1E1B18 面 #FF9F1C 引线 #FF5A1F 主行动 #3ECF8E 永久 等宽数字寿命引线沉浸取景
  • ＋ 与"相机工具"心智完全一致，相机-首页-详情视觉贯通；倒计时/引线在暗底上最醒目，"燃尽感"直击"临时"主题
  • － 长时间浏览宫格的舒适度低于浅色；亮环境下屏幕反光时可读性略降
方案 B

清单 Checklist

暖纸浅色 · 管理优先

把应用当成一张"待办清单"来设计：暖纸白底、墨色文字、品牌橙只出现在行动点。签名元素是首页顶部的"寿命分布条"——一根按三桶比例分段的横条，照片存量的整体态势一眼可读；宫格按到期日分组（今天 / 更早），像整理票据一样管理临时照片。适合照片数量多、以"查和管理"为主的使用方式。

#F7F6F3 底 #FFFFFF 卡 #1C1A17 墨 #D97706 今日 #E64A19 行动 分布条到期分组纸感留白
  • ＋ 浏览与管理最舒适，信息密度最友好；分布条对存量态势的表达是三案中最直观的
  • － 与"相机工具"的气质契合度一般，相机页在浅色框架中沉浸感最弱；差异化记忆点偏少
方案 C

昼夜 Day & Night

浅色首页 · 沉浸深色拍摄与详情

白天是清单，夜晚是暗房：首页与列表保持清爽冷白，进入相机与详情的瞬间切换为纯黑沉浸态，形成"日常管理 / 专注拍摄"的昼夜分界。签名元素有二：首页以大字宣言（"拍一张，今天就会消失的照片"）替代常规标题；详情页改为底部抽屉（Bottom Sheet）——大图沉在纯黑里，信息与操作收进白色圆角抽屉，剩余寿命用进度环表达。三案中交互最现代的一版。

#F2F4F7 日 #0A0A0A 夜 #F4511E 行动 #17191D 墨 #3ECF8E 永久 昼夜分界底部抽屉寿命进度环
  • ＋ 各取所长：管理舒适、拍摄沉浸；底部抽屉 + 进度环的详情页交互最现代，分享场景的仪式感最强
  • － 需要维护日/夜两套色板；页面间明暗切换存在视觉跳变，统一性弱于 A

回复 方案 A / B / C 即可选定方向；也可以指定混搭（如"A 的暗房首页 + C 的抽屉详情页"）。

选定后将以 ArkUI 状态管理 V2 落地：Index / CameraPage / DetailPage + StatsHeader / PhotoGridItem / DurationSelector 全部按稿重写样式层，业务逻辑不动。
